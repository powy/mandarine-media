# Assets Directory

This directory contains icons and assets for the Media Analyzer application.

## Required Icons for Packaging

- `icon.ico` - Windows icon (256x256 recommended)
- `icon.icns` - macOS icon 
- `icon.png` - Linux icon (512x512 recommended)

## Creating Icons

You can use online tools or image editors to create icons from a base image:

1. Create a 512x512 PNG image with your desired design
2. Convert to .ico format for Windows using online converters
3. Convert to .icns format for macOS using online converters
4. Keep the PNG for Linux

For now, the build process will work without icons, but may show warnings.

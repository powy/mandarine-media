🎬 KYOOL Media Uploader

Guide complet d'utilisation de l'outil de téléversement de médias unifié. Gérez vos vidéos, images et sous-titres vers Mux et AWS S3 en toute simplicité.

Version 1.0.0

🎯 Introduction et Vue d'Ensemble

▼

KYOOL Media Uploader est un outil professionnel de téléversement de médias qui consolide plusieurs utilitaires en un seul système complet. Il gère l'ensemble du flux de travail de publication de contenu multimédia.

Capacités Principales

🎥 Vidéos

Téléversement vers Mux avec encodage automatique et streaming adaptatif

🖼️ Images

Upload vers AWS S3 avec support multi-résolutions (posters, vignettes)

📝 Sous-titres

Gestion des sous-titres multilingues (FR, EN, KO) vers S3

📊 Métadonnées

Gestion via Excel et synchronisation avec l'API backend

Fonctionnalités Clés

  • Analyse de médias - Scan automatique des dossiers et association des fichiers
  • Traitement par lots - Gestion de médias uniques ou de saisons complètes
  • Workflow Excel - Interface Excel pour les métadonnées et la gestion des fichiers
  • Support multi-plateformes - Mux pour vidéos, S3 pour images/sous-titres
  • Gestion des tâches - Suivi en temps réel avec logs et progression
Architecture en Deux Services :
  • Service-Server (Port 3011) - Gestion et exécution des tâches
  • Service-Interface (Port 3010) - Interface web React en temps réel

🚀 Démarrage Rapide

▼

Installation et Lancement

Étape 1 : Lancement de l'Application

Double-cliquez sur START.bat dans le dossier d'installation.

Résultat :
  • Serveur démarré sur le port 3011
  • Interface web ouverte automatiquement sur http://localhost:3010
  • Indicateur de connexion vert dans l'en-tête

Étape 2 : Préparation du Fichier de Configuration

Créez un fichier .ini avec vos identifiants d'accès (voir section Configuration pour les détails).

Étape 3 : Premier Upload

  1. Dans l'interface web, entrez le chemin vers votre fichier de configuration
  2. Entrez le chemin du dossier contenant votre média
  3. Cliquez sur "Prépare un Excel" pour générer le fichier de métadonnées
  4. Remplissez les informations dans le fichier Excel
  5. Cliquez sur "Upload un Media" pour lancer le téléversement

Prérequis Système

Composant Requis
Système d'exploitation Windows 10/11 (64-bit)
Node.js Version 18 ou supérieure
RAM 2 Go minimum
Espace disque ~200 Mo pour l'application
Connexion Internet Requise pour les uploads
Important : Ne pas installer dans C:\Program Files\ pour éviter les problèmes de permissions. Utilisez un répertoire accessible en écriture.

🖥️ Interface Utilisateur

▼

L'interface web est accessible sur http://localhost:3010 après le lancement. Elle est divisée en quatre sections principales.

Section A : ENTRÉES

Champs de saisie pour configurer vos opérations :

Champ Description
Fichier de configuration Chemin vers votre fichier .ini contenant les identifiants
Dossier Chemin du dossier contenant un média unique
Dossier parent Chemin du dossier parent pour traitement par lots (saisons)
Chemin de l'image Chemin vers un fichier image à uploader
Résolution image Format de l'image (1920x1080, 1080x1080, etc.)
Chemin du sous-titre Chemin vers un fichier de sous-titre
Langue Langue du sous-titre (Français, English, Korean)
ID Description Média UUID backend du média (optionnel)
ID Entité Saison UUID backend de la saison (optionnel)
ID Asset Mux ID Mux direct (optionnel)
Champ Excel / Nouvelle valeur Pour édition de champs Excel en masse

Section B : ACTIONS

Les actions sont organisées en 4 catégories :

Catégorie 1 : TÉLÉVERSEMENT

Opérations Uniques (1.A)

  • Prépare un Excel - Génère un fichier Excel pour un média
  • Upload un Media - Téléverse un média complet

Opérations par Lots (1.B)

  • Prépare des Excels - Génère Excel pour tous les sous-dossiers
  • Upload des Medias - Téléverse tous les médias d'un dossier parent

Catégorie 2 : MISE À JOUR DEPUIS EXCEL

Opérations Uniques (2.A)

  • Charge une Image - Upload d'une image unique
  • Charge un Sous-titre - Upload d'un sous-titre unique
  • Recharge Sous-titres - Réimporte tous les sous-titres d'un média

Opérations par Lots (2.B)

  • Charge Images pour Tous - Upload images pour tous les médias
  • Recharge Tous Sous-titres - Réimporte tous les sous-titres de la saison
  • Propager Données Saison - Copie métadonnées de saison vers épisodes

Catégorie 3 : MISE À JOUR PAR ID

Opérations ciblées utilisant les identifiants backend ou Mux :

  • Sous-titre par ID Description - Upload via UUID backend
  • Sous-titre par Asset Mux - Upload via ID Mux
  • Image par ID - Upload image via UUID backend
  • Supprimer Sous-titre - Suppression d'un sous-titre
  • Upload Sous-titres par ID et Dossier - Batch via UUID
  • Sous-titres pour Saison - Batch pour une saison entière
  • Propager Saison par ID Description/Entité - Propagation ciblée

Catégorie 4 : EDITION EXCELS

Opérations Uniques (4.A)

  • Modifier un Excel - Édite un champ dans un fichier Excel

Opérations par Lots (4.B)

  • Modifier Tous les Excels - Édite tous les fichiers d'un dossier
  • Régénérer Noms Épisodes - Reconstruit les noms automatiquement

Section C : TÂCHES

Suivi en temps réel de vos opérations :

  • Tâches en Cours - Liste des opérations actives avec progression
  • Tâches Terminées - Historique avec statuts (succès, échec, partiel)
  • Sélection de tâche - Cliquez pour voir les logs détaillés

Section D : JOURNAL

Visualisation des logs :

  • Affichage en temps réel des logs de la tâche sélectionnée
  • Défilement automatique activé par défaut
  • Codes couleur pour les différents niveaux (info, erreur, succès)
En-tête de l'interface :
  • Indicateur de connexion - Vert = connecté, Rouge = déconnecté
  • Version - Numéro de version actuelle (v1.0.0)

⚙️ Workflows Étape par Étape

▼

Workflow 1 : Upload d'un Média Unique (Complet)

Étape 1 : Démarrer l'Application

Double-cliquez sur START.bat

Résultat : Serveur démarré sur port 3011, interface ouverte sur http://localhost:3010

Étape 2 : Préparer les Entrées

Dans l'interface web :

  1. Entrez le chemin du fichier de configuration (ex: C:\config\kyool.ini)
  2. Entrez le chemin du dossier contenant le média (ex: C:\Medias\Episode01)

Étape 3 : Préparer l'Excel

  1. Cliquez sur "Prépare un Excel" (Catégorie 1.A)
  2. Le système crée 0_desc_[NOM_DOSSIER]_auto.xlsx
  3. Excel s'ouvre automatiquement avec deux feuilles :
    • Description - Métadonnées du média
    • Files - Mappage des fichiers

Étape 4 : Remplir le Fichier Excel

Feuille "Description" - Remplissez les champs :

  • Titre du média
  • Synopsis
  • Catégories
  • Tags
  • Autres métadonnées pertinentes

Feuille "Files" - Indiquez les noms de fichiers :

  • Nom du fichier vidéo
  • Noms des fichiers posters (différentes résolutions)
  • Noms des fichiers de sous-titres (par langue)

Étape 5 : Lancer l'Upload

  1. Retournez à l'interface web
  2. Vérifiez que les mêmes entrées sont présentes (config + dossier)
  3. Cliquez sur "Upload un Media" (Catégorie 1.A)
  4. Surveillez la progression dans "Tâches en Cours"
  5. Visualisez les logs en temps réel dans la section "Journal"
Résultat : Média complet téléversé avec vidéo (Mux), images (S3), sous-titres (S3), et métadonnées (Backend API).

Workflow 2 : Upload par Lots (Saison avec Épisodes)

Étape 1 : Organiser la Structure des Dossiers

Structurez vos fichiers comme suit :

Saison01/ ├── 01/ │ ├── episode01.mp4 │ ├── poster_1920x1080.jpg │ ├── poster_1080x1080.jpg │ ├── sub_fr.vtt │ └── sub_en.vtt ├── 02/ │ ├── episode02.mp4 │ ├── poster_1920x1080.jpg │ └── ... └── 03/ └── ...

Étape 2 : Préparer Tous les Excels

  1. Entrez le chemin du dossier parent : C:\Medias\Saison01
  2. Cliquez sur "Prépare des Excels" (Catégorie 1.B)
  3. Un Excel est créé dans le dossier parent ET dans chaque sous-dossier

Étape 3 : Remplir l'Excel Parent (Saison)

Remplissez les métadonnées au niveau de la saison dans le fichier Excel du dossier parent.

Étape 4 : Remplir les Excels des Épisodes

Remplissez les métadonnées spécifiques à chaque épisode dans leurs fichiers Excel respectifs.

Étape 5 : Lancer l'Upload par Lots

  1. Cliquez sur "Upload des Medias" (Catégorie 1.B)
  2. Le système traite tous les sous-dossiers en parallèle
  3. Chaque épisode est uploadé indépendamment
  4. Suivez la progression de chaque tâche dans la section "Tâches"

Étape 6 : Propager les Données de Saison (Optionnel)

Pour copier les métadonnées communes de la saison vers tous les épisodes :

  1. Cliquez sur "Propager Données de Saison" (Catégorie 2.B)
  2. Les champs communs sont copiés du parent vers tous les enfants

Workflow 3 : Mise à Jour d'Éléments Spécifiques

Ajouter une Image à un Média Existant

  1. Entrez le chemin du dossier du média
  2. Entrez le chemin de l'image
  3. Sélectionnez la résolution (ex: 1920x1080)
  4. Cliquez sur "Charge une Image" (Catégorie 2.A)

Ajouter/Mettre à Jour des Sous-titres

  1. Entrez le chemin du dossier du média
  2. Entrez le chemin du fichier de sous-titre
  3. Sélectionnez la langue (Français, English, Korean)
  4. Cliquez sur "Charge un Sous-titre" (Catégorie 2.A)

Éditer un Champ Excel sur Tous les Épisodes

  1. Entrez le chemin du dossier parent
  2. Sélectionnez le champ à modifier dans le menu déroulant (ex: "Catégories")
  3. Entrez la nouvelle valeur
  4. Cliquez sur "Modifier Tous les Excels" (Catégorie 4.B)
Astuce : Utilisez les opérations par ID (Catégorie 3) pour des mises à jour ciblées sans avoir besoin des fichiers Excel locaux.

⚙️ Configuration

▼

Fichier de Configuration (.ini)

Le fichier de configuration utilise le format INI standard et contient tous vos identifiants et paramètres.

Structure Complète du Fichier

[general] verbose = true maxConcurrentUploads = 5 retryAttempts = 3 retryDelay = 2000 [backend] baseUrl = https://api.kyool.com username = votre_utilisateur password = votre_mot_de_passe [mux] tokenId = votre_token_id_mux tokenSecret = votre_token_secret_mux [s3] accessKeyId = votre_access_key_aws secretAccessKey = votre_secret_key_aws region = eu-west-3 [s3.pictures] bucket = kyool-pictures keyPrefix = medias/images/ [s3.subtitles] bucket = kyool-subtitles keyPrefix = medias/subtitles/ [logging] enabled = true level = info file = logs/uploader.log console = true

Description des Sections

[general] - Paramètres Généraux

Paramètre Description Valeurs
verbose Active les logs détaillés true / false
maxConcurrentUploads Nombre max d'uploads parallèles 1-1000 (recommandé: 3-10)
retryAttempts Nombre de tentatives en cas d'échec 1-10 (recommandé: 3)
retryDelay Délai entre les tentatives (ms) 1000-10000 (recommandé: 2000)

[backend] - API Backend KYOOL

Paramètre Description
baseUrl URL de base de l'API backend
username Nom d'utilisateur pour l'authentification
password Mot de passe pour l'authentification

[mux] - Plateforme Mux Video

Paramètre Description
tokenId ID du token API Mux
tokenSecret Secret du token API Mux

[s3] - AWS S3 (Général)

Paramètre Description
accessKeyId Clé d'accès AWS
secretAccessKey Clé secrète AWS
region Région AWS (ex: eu-west-3, us-east-1)

[s3.pictures] et [s3.subtitles] - Buckets S3

Paramètre Description
bucket Nom du bucket S3
keyPrefix Préfixe du chemin dans le bucket (ex: medias/images/)

[logging] - Configuration des Logs

Paramètre Description Valeurs
enabled Active/désactive les logs true / false
level Niveau de log debug, info, warn, error
file Chemin du fichier de log Chemin relatif ou absolu
console Affiche les logs dans la console true / false
Sécurité : Ne jamais partager votre fichier de configuration. Il contient des identifiants sensibles. Stockez-le dans un emplacement sécurisé et ne le commitez pas dans un système de contrôle de version.

Données de l'Application

🔧 Résolution de Problèmes

▼

Problèmes Courants et Solutions

Problème : Les Ports Sont Déjà Utilisés

Symptôme : L'application ne démarre pas ou affiche une erreur "Port already in use".

Solutions :

  1. Vérifiez si une autre instance est déjà en cours d'exécution
  2. Fermez les applications utilisant les ports 3010 ou 3011
  3. Utilisez la commande pour identifier les processus :
    netstat -ano | findstr :3010 netstat -ano | findstr :3011
  4. Arrêtez le processus concerné ou redémarrez l'ordinateur

Problème : Erreurs de Permission

Symptôme : "Access denied" ou erreurs lors de l'écriture de fichiers.

Solutions :

  • N'installez PAS dans C:\Program Files\
  • Utilisez un répertoire utilisateur (ex: C:\Users\VotreNom\MediaUploader\)
  • Exécutez en tant qu'administrateur (clic droit > Exécuter en tant qu'administrateur)
  • Vérifiez les permissions du dossier de destination

Problème : Erreurs de Configuration

Symptôme : "Configuration error" ou échec d'authentification.

Solutions :

  1. Vérifiez le format du fichier .ini (pas d'espaces superflus)
  2. Validez que tous les identifiants sont corrects
  3. Vérifiez que les chemins utilisent des barres obliques inversées doubles (\\) ou simples (/)
  4. Testez les identifiants manuellement (API backend, Mux, AWS)

Problème : Échecs d'Upload

Symptôme : Tâches marquées comme "failed" ou uploads incomplets.

Solutions :

  • Vérifiez votre connexion Internet
  • Consultez les logs détaillés dans la section Journal
  • Vérifiez les identifiants API (Mux, AWS, Backend)
  • Réduisez maxConcurrentUploads dans la config si problèmes de bande passante
  • Augmentez retryAttempts pour connexions instables
  • Vérifiez que les buckets S3 et permissions sont corrects

Problème : Excel Ne S'Ouvre Pas Automatiquement

Symptôme : Fichier Excel créé mais pas ouvert.

Solutions :

  • Vérifiez que Microsoft Excel est installé
  • Ouvrez manuellement le fichier 0_desc_[NOM]_auto.xlsx dans le dossier
  • Associez les fichiers .xlsx à Excel dans Windows

Problème : Interface Web Ne Se Charge Pas

Symptôme : Page blanche ou "Connection refused" dans le navigateur.

Solutions :

  1. Vérifiez que le serveur est démarré (indicateur vert)
  2. Accédez manuellement à http://localhost:3010
  3. Vérifiez les logs de démarrage dans le dossier logs\
  4. Désactivez temporairement le pare-feu/antivirus
  5. Essayez un autre navigateur
  6. Effacez le cache du navigateur

Gestion des Erreurs Intégrée

L'application dispose de mécanismes automatiques de gestion des erreurs :

  • Retry automatique avec backoff exponentiel
  • Délais adaptatifs selon les conditions réseau
  • Circuit breaker pour échecs persistants
  • Reprise d'upload en cas d'interruption
  • Logs détaillés pour diagnostic

Emplacements des Logs

Pour diagnostiquer les problèmes, consultez les logs dans :

  • Console - Sortie en temps réel (si activée)
  • %APPDATA%\Kyool\MediaUploader\logs\ - Logs persistants
  • Interface web, section Journal - Logs par tâche
  • Dossier d'installation\logs\ - Logs de démarrage
Astuce : Activez verbose = true dans votre fichier de configuration pour obtenir des logs plus détaillés lors du diagnostic de problèmes.

Support et Aide Supplémentaire

Si le problème persiste :

  1. Collectez les logs pertinents
  2. Notez les étapes pour reproduire le problème
  3. Vérifiez la version de l'application (affichée dans l'en-tête)
  4. Contactez le support technique avec ces informations

🚀 Fonctionnalités Avancées

▼

Intégration Excel Avancée

Auto-remplissage à Partir des Fichiers Scannés

Lors de la préparation d'un Excel, l'application :

  • Scanne automatiquement le dossier
  • Détecte les fichiers vidéo, images et sous-titres
  • Pré-remplit la feuille "Files" avec les noms détectés
  • Propose des suggestions basées sur les conventions de nommage

Variables Dynamiques

Utilisez des variables dans vos fichiers Excel :

{{ folder_name }} # Nom du dossier parent {{ episode_number }} # Numéro d'épisode auto-détecté {{ season_name }} # Nom de la saison

Ces variables sont automatiquement remplacées lors du traitement.

Édition par Lots de Champs Excel

Modifiez simultanément un champ dans tous les fichiers Excel d'une saison :

  1. Sélectionnez le champ dans le menu déroulant
  2. Entrez la nouvelle valeur
  3. L'opération s'applique à tous les sous-dossiers

Régénération Automatique des Noms d'Épisodes

Reconstruit automatiquement les noms d'épisodes basés sur :

  • Le nom de la saison parent
  • La numérotation séquentielle des dossiers
  • Les patterns de nommage configurés

Opérations Basées sur les ID

Opérations par ID Backend (UUID)

Effectuez des mises à jour sans avoir les fichiers Excel locaux :

  • Upload de sous-titres par Media Description ID
  • Upload d'images par ID
  • Propagation de saison par Entity ID

Utile pour les opérations à distance ou les corrections rapides.

Opérations par Mux Asset ID

Interagissez directement avec la plateforme Mux :

  • Ajout de sous-titres à un asset Mux existant
  • Mise à jour de métadonnées
  • Gestion indépendante du workflow backend

Traitement Parallèle

Configuration du Parallélisme

Paramètre maxConcurrentUploads (1-1000) :

Valeur Usage Recommandé
1-3 Connexion lente ou médias très lourds
5-10 Usage standard (recommandé)
10-50 Connexion rapide, nombreux petits fichiers
50+ Serveurs haute performance, usage professionnel

Démarrage Échelonné

Pour éviter la surcharge :

  • Les tâches démarrent progressivement
  • Délai automatique entre les démarrages
  • Prévention de la saturation réseau

Suivi Indépendant des Tâches

Chaque tâche :

  • S'exécute dans son propre processus
  • A ses propres logs
  • Peut échouer sans affecter les autres
  • Peut être relancée individuellement

Gestion Avancée des Saisons

Relations Parent-Enfant

Structure hiérarchique automatiquement détectée :

Saison/ # Parent ├── 01/ # Enfant (épisode) ├── 02/ # Enfant (épisode) └── 03/ # Enfant (épisode)

Numérotation Automatique des Épisodes

Basée sur :

  • L'ordre alphabétique des dossiers
  • Les numéros dans les noms de dossiers
  • La configuration personnalisée

Propagation de Données

Copiez des métadonnées communes du parent vers tous les enfants :

  • Catégories
  • Tags
  • Informations de production
  • Champs personnalisés

Les champs spécifiques aux épisodes (titre, synopsis, etc.) restent inchangés.
